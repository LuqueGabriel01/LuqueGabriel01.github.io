# Portfolio

Personal portfolio backend developer. A static, single-page website showcasing my projects, tech stack and contact details.

🔗 https://luquegabriel01.github.io

## Tech stack

- [Astro](https://astro.build) + TypeScript
- [Tailwind CSS](https://tailwindcss.com) v4
- ESLint + Prettier, Husky + lint-staged and commitlint
- GitHub Actions for CI and deployment to GitHub Pages

## Local development

Requirements: Node 24.

```bash
git clone https://github.com/LuqueGabriel01/LuqueGabriel01.github.io.git
cd LuqueGabriel01.github.io
npm install
npm run dev
```

Other commands: `npm run build`, `npm run lint`, `npm run format`.
